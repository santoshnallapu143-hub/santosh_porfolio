# Santosh Nallapu — Academic Portfolio

Clean blue, black and white academic research portfolio. Static HTML/CSS/JS; no build step required.

## Preview
Open `index.html` in your browser. For local development, use VS Code Live Server or `python -m http.server 8000`.

## Publish
Upload the contents of this folder to a GitHub repository and enable GitHub Pages in Settings → Pages → Deploy from a branch, selecting `main` and `/ (root)`.

## Before publishing
- Verify every project description and current status.
- Add actual GitHub, LinkedIn, ORCID, and Scholar links only if accounts exist.
- Add verified publications and project repository links once available.
- Review mobile and desktop layouts.
- Replace the illustrative DNA graphic if you prefer a portrait.
